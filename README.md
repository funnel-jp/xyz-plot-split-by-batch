# xyz-plot-split-by-batch

Stable Diffusion WebUI forge neoの標準スクリプトである「X/Y/Z Plot」を改良し、バッチサイズ > 1 の生成時にグリッドをバッチ単位で分割して出力できるようにするカスタムスクリプトです。

## 概要

通常の X/Y/Z Plot では、メイン設定の `Batch size` を 2 以上に設定すると、巨大なグリッドが生成されて各画像は豆粒になってしまいます。

このスクリプトを導入すると、X/Y/Z Plot ではなく **「X/Y/Z plot split by batch」** が追加されます。これを有効にすることで、バッチ内の各画像（1枚目、2枚目...）ごとに独立した比較グリッド画像を生成・保存できるようになります。シード値の変動やControlNet等の挙動をバッチ単位で検証したい場合に便利です。

## 機能

* **Draw legend for X/Y**: 凡例ラベルの有無を軸ごとに指定できます。なお、Z軸のラベルは常に表示されません。
* **Use newline separator**: カンマ区切りではなく改行区切りで軸の値を記述します。空白にしたい場合は""か''を入れるか、２回改行してください。

## インストール方法

1.  WebUI の `Extensions` タブを開きます。
2.  `Install from URL` を選択します。
3.  このリポジトリの URL を入力し、`Install` をクリックします。
4.  WebUI を再起動（Reload UI）します。
